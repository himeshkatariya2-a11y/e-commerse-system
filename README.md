📌 About the Project

This is a console-based E-Commerce Management System developed using C++. It is designed to provide basic shopping functionality through a simple menu-driven interface.

✨ Features

- Display available products
- Add products to cart
- View shopping cart
- Menu-driven user interface
- Basic shopping operations

🛠️ Technologies Used

- Language: C++
- Concepts: Conditional Statements, Loops, Arrays, Functions (if used), and Basic Programming Logic

▶️ How to Run

1. Clone or download this repository.
2. Open the ".cpp" file in VS Code or any C++ IDE.
3. Compile the program.
4. Run the executable.

🎯 Project Objective

The objective of this project is to strengthen C++ programming skills by building a basic shopping system and understanding how e-commerse operations work.
